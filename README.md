# PiShell

PiShell is a simple shell written in C++ for embedded systems.

PiShell is also my first attempt at writing a scripting language, which is why this project likely has a lot of bad practices and a noticeable lack of features.

This project is the result of me exploring something totally new to me. Use this at your own risk.

### Capabilities

This is a work in progress and the capabilities will likely expand as the project grows in size.

- 32 registers storing 64-bit integers
- Basic arithmetic operations
- Basic input from user
- Basic control using conditional calls to functions

A list of some planned features that I can realistically implement:

- (In cooperation with my Pi kernel - soon to be uploaded on GitHub) Scriptable control of GPIO pins
- Control flow with all of the usual culprits (while, for, if/else)
- Dynamic memory usage
